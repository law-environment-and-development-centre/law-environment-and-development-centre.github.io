{%- comment -%} Renders a list of events from the _events folder, sorted and split by date. Parameters: which = "upcoming" (soonest first) or "past" (most recent first) limit = optional maximum number of upcoming events to show (e.g. on the homepage) full = true to show the description text under each event id = optional id for the list (the upcoming list moves events into the list with this id) past_target = id of the past list on the same page, if any empty = message to show when there are no events in this list Splitting happens twice: here when the site is built (so the page is right even without JavaScript), and again in the browser by assets/js/events.js, so an event moves to "past" as soon as it ends even if nobody has rebuilt the site since. All times are UK time (timezone in _config.yml). An event counts as finished at its end time ("end:" in the event file), or two hours after it starts if no end time is given, or at the end of the day for events with a date but no time. {%- endcomment -%} {%- assign now = site.time | date: "%s" | plus: 0 -%} {%- assign sorted = site.events | sort: "date" -%} {%- if include.which == "past" -%}{%- assign sorted = sorted | reverse -%}{%- endif -%} {%- assign shown = 0 -%}
